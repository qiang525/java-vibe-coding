# 学习顺序（照着这张表一个一个往下走）

> ⚠️ **先说一件重要的事**：
> `docs/手把手教学/` 里的文件名是 `00` 到 `09`，**但那个编号不是学习顺序**。
> 真正的顺序是下面这张表：**00 → 07 → 01 → 02 → 03 → 04 → 05 → 08 → 09**。
> 别按文件夹里的名字顺序看，会看错。

## 二、三种走法（按你的时间选）

### 🟢 只有 15 分钟：只做第 1 步 + 一件小事

```
看 00-先认识这些文件.md 的前三节（文件后缀是什么）
然后双击 tools\check-env.bat，看 5 项检查结果
```

**目的**：和这个项目产生第一次真实接触。

---

### 🟡 每周只有 30 分钟：走前 5 步（约 2.5 小时，分 5 周）

```
第 1 周  第 1 步：先认识这些文件
第 2 周  第 2 步：电脑基本功（分两次看）
第 3 周  第 3 步：环境准备
第 4 周  第 4 步：启动项目      ← 关键的一周
第 5 周  第 5 步：功能走查
```

**走完这 5 步，你就已经能随时把网站打开演示给别人看了。**
后面 6-9 步可以搁置，不会退步（忘了就回来重看第 4 步）。

> 之后每周固定做一件事：**双击 3 个 bat，打开 8080 点 5 分钟，关掉。**
> 这 5 分钟能防止你"一周不碰就彻底放下"。

---

### 🔵 有整块时间（假期）：10 步全走完（约 5 小时 + 练手时间）

```
Day 1  出发前 + 第 1、2 步        地基
Day 2  第 3、4 步                 跑起来
Day 3  第 5 步 + 自己玩一遍        走查
Day 4  第 6、7 步                 改和看数据
Day 5  第 8、9 步                 学 Git 并推上去
```

## 三、每步的"卡住了怎么办"

| 卡在哪 | 症状 | 去看 |
|---|---|---|
| 第 1 步 | 不知道"后缀"在哪看 | 该册第二节：怎么显示文件扩展名 |
| 第 2 步 | 命令行打不开 / 命令不存在 | 该册第 4 节 + `06-故障排查.md` 对应条目 |
| 第 3 步 | `java -version` 不是 11 | 该册第 1 节"如果不对怎么办" + 跑 `tools\fix-java-path\run-fix.bat` |
| 第 4 步 | 双击 bat 一闪就没 | `06-故障排查.md` **F01** |
| 第 4 步 | 8080 被占用 | **F02** |
| 第 4 步 | Redis 连不上 | **F03** |
| 第 4 步 | 数据库密码错 | **F04** |
| 第 4 步 | 网页全白 | **F05** |
| 第 4 步 | IDEA 里代码全红 | **F10**（Maven 依赖没下完，等） |
| 第 5 步 | 页面按钮和我看到的不一样 | 先把浏览器窗口拉宽（窄屏会隐藏部分元素） |
| 第 6 步 | 改了代码没反应 | 该册 2.7 节"四步排查" |
| 第 7 步 | IDEA 连不上数据库 | `06-故障排查.md` **F04** / **F22**（时区） |
| 第 8 步 | `git push` 被拒绝 | `09-Git分支与冲突.md` 第 8 节报错速查 |
| 第 9 步 | 冲突标记看不懂 | 该册 6.4 节（有完整示例） |

**通用兜底**：把报错**截图**发给 AI，说"我卡在第 N 步"。

## 六、关于"文件名编号"

你可能已经发现：文件名是 `00` `01` `02`…`09`，但学习顺序是 `00 → 07 → 01 → 02…`。

**为什么这样**：`00` 到 `09` 是按"主题类型"排的（认识文件 / 环境 / 启动 / 走查 / 改代码 / 数据库 / 排错 / 电脑基础 / Git 入门 / Git 进阶）。

**你不需要记住这些编号。** 只需要照着上面第一张表，从上往下走。
每册开头也都标了「这是第 N 步」，翻到任何一册都能知道自己走到哪了。
