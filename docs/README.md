## 二、两类文档，别混着读

### 🔧 操作类（讲"怎么做"，跟着敲）

| 文档 | 一句话 |
|---|---|
| `零基础学习路线图.md` | 6 个阶段 + 3 种时间方案 + 不要学什么 |

## 三、推荐的阅读顺序（三档）

### 第一档：只想看效果（1 小时）

```
START-HERE.md（项目根目录）
  → 手把手教学/02-启动项目.md
  → 手把手教学/03-功能走查.md
```

### 第二档：想学完整流程（约 47 小时，可拆成 3 个月）

按 [`零基础学习路线图.md`](零基础学习路线图.md) 的 6 个阶段走：

```
阶段0 地基 → 阶段1 会看 → 阶段2 会跑 → 阶段3 看请求
   → 阶段4 读代码 → 阶段5 会改 → 阶段6 上线（可选）
```

对应的文档：

| 阶段 | 主看 |
|---|---|
| 0 地基 | `手把手教学/07-电脑基本功.md` + `00-先认识这些文件.md` |
| 1 会看 | `手把手教学/03-功能走查.md` + `README.md`（项目根）前三节 |
| 2 会跑 | `手把手教学/01-环境准备.md` + `02-启动项目.md` |
| 3 看请求 | `手把手教学/05-数据库与接口.md` |
| 4 读代码 | `技术架构与中间件全景.md` + 直接读源码 |
| 5 会改 | `手把手教学/04-修改与打包.md` + `项目体检报告.md` 的 R3/R4 |
| 6 上线 | `部署上线指南.md` |

### 第三档：只想理解设计（不实操）

```
技术架构与中间件全景.md
  → 数据库表设计详解.md
  → 接口清单.md
  → 完整开发流程手册.md
```
