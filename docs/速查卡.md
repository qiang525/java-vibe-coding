## ⬆️ 每天开机：3 步（约 30 秒）

| 步 | 动作 | 成功标志 |
|---|---|---|
| 1 | 双击 `tools\start-redis.bat` | 窗口出现 `Ready to accept connections` → **最小化，别关** |
| 2 | 双击 `tools\start-backend.bat` | 窗口出现 `Started CourseHubApplication` |
| 3 | 浏览器打开 `http://localhost:8080` | 紫色界面 + 右上角能登录 |

> MySQL 是开机自启的，不用管。

## ⬇️ 关机前：2 步

| 步 | 动作 |
|---|---|
| 1 | 后端窗口按 `Ctrl + C`（或 IDEA 点红色 ⏹） |
| 2 | 关掉 Redis 黑窗口 |

## 🚨 五个最常见的坑（一句话修法）

| 现象 | 一句话修法 |
|---|---|
| 双击 bat 一闪就没 | 用命令行跑（地址栏敲 `cmd`），能看到报错 → 详见 F01 |
| `Port 8080 was already in use` | 之前的服务没关。`netstat -ano \| findstr ":8080"` 查 PID → `taskkill /F /PID 数字` → F02 |
| Redis 连不上 | 那个黑窗口被关了 → 重新双击 `start-redis.bat` → F03 |
| 数据库密码错 | 检查 `application-local.yml` 里的密码 → F04 |
| 网页全白 | 后端没启动；按 `F12` 看 Console 红字 → F05 |

## ✅ 验证服务好不好（不用打开网页）

```
"E:\java\redis\redis-cli.exe" ping          → PONG = Redis 好
netstat -ano | findstr ":3306"              → 有 LISTENING = MySQL 好
netstat -ano | findstr ":8080"              → 有 LISTENING = 后端好
```

三项全过 = 一切正常。
