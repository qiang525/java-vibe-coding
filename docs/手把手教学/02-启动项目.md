# 第 ② 册 · 启动项目

> 目标：让 `http://localhost:8080` 打开一个能登录、能看资料的网站。
> 全流程 4 个动作：确认 MySQL → 启动 Redis → 启动后端 → 打开浏览器。

---

## 0. 先理解"单端口"这件事

很多人第一次做 Java Web 会困惑：
"前后端分离，那不是要启动两个服务、开两个端口吗？"

**本项目支持两种模式，第一次先用简单的那种。**

| | 模式 A：单端口（本册讲） | 模式 B：前后端分开（④ 册讲） |
|---|---|---|
| 启动几个 | 只启动后端 | 后端 + 前端 Vite |
| 浏览器地址 | `http://localhost:8080` | `http://localhost:5173` |
| 适合 | 看效果、演示、交作业 | 改前端代码（改完自动刷新） |
| 原理 | 前端已打包成静态文件，放在 `backend/src/main/resources/static`，由后端一起托管 | 前端跑自己的服务器，`/api` 请求转发给后端 |

**为什么打包进去就能用？** 因为 Spring Boot 默认会把
`src/main/resources/static/` 目录当成网站的根目录。浏览器请求 `/`，
它就把 `static/index.html` 返回给你；请求 `/api/courses`，才走 Java 代码。

本项目还特意把前端路由改成了 **hash 模式**（地址栏里带 `#`，
比如 `http://localhost:8080/#/courses`），这样刷新页面不会 404，不需要额外的服务器配置。

## 1. 动作一：确认 MySQL 在跑

```
netstat -ano | findstr ":3306" | findstr "LISTENING"
```

有输出 = 在跑，直接跳到第 2 节。
没输出 = 停掉了，按 ① 册第 3.2 节启动它。

> MySQL 一般是开机自启的服务，装好之后基本不用管。这一步只是"确认"，不是"每次都要启动"。

---

## 2. 动作二：启动 Redis

1. 打开文件夹 `D:\桌面\Java项目AIGC\tools`
2. **双击 `start-redis.bat`**
3. 等窗口里出现 `Ready to accept connections`
4. **把这个窗口最小化，不要关**

### 验证（可选但推荐）

另开一个命令行：

```
E:\java\redis\redis-cli.exe ping
```

返回 `PONG` 就对了。

> 如果你之前已经启动过 Redis（窗口还在任务栏），这一步可以跳过。
> 判断方法就是上面那条 `ping` 命令。

## 3. 动作三：启动后端（两种方式，选一种）

### 方式 1：用 IDEA 启动（推荐，学习价值高）

#### 3.1 打开项目

1. 启动 IntelliJ IDEA
2. 欢迎界面点 **`Open`**（如果已经打开了别的项目，用菜单 `File` → `Open`）
3. 在弹出的文件选择框里，**定位到**：

```
D:\桌面\Java项目AIGC\backend
```

   ⚠️ **一定要选 `backend` 这个文件夹，不是外层的 `Java项目AIGC`**。
   因为 `pom.xml`（Maven 的身份证）在 `backend` 里面，IDEA 靠它识别项目。

4. 点 `OK`
5. 如果弹出 "Trust Project?"，点 **`Trust Project`**

#### 3.2 等它"醒过来"

打开后你会看到右下角有进度条在转，可能在下载 Maven 依赖。
**第一次打开可能要 3-10 分钟**（取决于网速和本地有没有缓存）。

判断"醒过来"的标志：
- 右下角的进度条全部消失
- 左侧 `Project` 面板里，`src/main/java` 下的文件图标是**蓝色的 C**（不是红色的 J）
- 底部状态栏没有 "Loading..." 之类的字样

如果代码大面积飘红（红色文字），看 ⑥ 册 F10。

#### 3.3 确认 JDK 是 11

菜单 `File` → `Project Structure...` → 左侧 `Project` → `SDK` 选 11。
（① 册第 6.2 节已讲过，没做过的现在做）

#### 3.4 找到启动类并运行

1. 左侧 `Project` 面板，依次展开：

```
backend
 └ src
    └ main
       └ java
          └ com.nnuist.coursehub
             └ CourseHubApplication        ← 就是这个，图标是蓝色 C 带绿色三角
```

2. **双击** `CourseHubApplication` 打开它
3. 你会看到代码里有一个 `public static void main(String[] args)` 方法
4. 这一行左边的行号区域（灰色竖条里）有一个**绿色三角形 ▶**
5. **点那个绿色三角** → 弹出小菜单 → 选 **`Run 'CourseHubApplication.main()'`**

   或者更简单：**右键** `CourseHubApplication` 文件 → `Run 'CourseHubApplication.main()'`

#### 3.5 看底部的 Run 面板

底部会弹出一个 `Run` 窗口，刷出一大堆日志。**这是正常的。**

成功时，最后几行长这样（关键行已标注）：

#### 3.6 千万别做的两件事

| 别做 | 后果 |
|---|---|
| 别点红色的方形"停止"按钮 | 服务会停，网页就打不开了 |
| 别关 IDEA | 同上。服务是"IDEA 里的进程"，IDEA 在服务在 |

要停止服务：点 Run 面板左边的**红色方块 ⏹**。这是正常关闭方式。

---

### 方式 2：双击脚本启动（最快，不想开 IDEA 时用）

1. 打开 `D:\桌面\Java项目AIGC\tools`
2. **双击 `start-backend.bat`**
3. 脚本会先检查 Redis，如果 Redis 没启动会提醒你
4. 然后自动执行 `mvn spring-boot:run`
5. 同样等 `Started CourseHubApplication in x.xxx seconds`
6. 关闭：在窗口里按 `Ctrl + C`，或直接关窗口

> 这个脚本做的其实就是 `cd backend` + `mvn spring-boot:run`，
> 加上自动设置 `JAVA_HOME=E:\java\jdk11`。
> 实测启动耗时约 15 秒（依赖已缓存的情况下）。

## 4. 动作四：打开浏览器

### 4.1 访问首页

打开 Chrome / Edge，地址栏输入：

```
http://localhost:8080
```

回车。

### 你应该看到

一个紫色渐变的顶部导航栏，左边是 `CourseHub` 标志，右边是「登录 / 注册」按钮，
中间是搜索框和几张卡片（"最新资料""热门课程"之类）。

> 如果页面全白：按 `F12` 打开开发者工具 → 看 `Console` 标签有没有红色报错，
> 然后去 ⑥ 册 F05。

### 4.2 登录

1. 点右上角 **「登录」**
2. 页面跳到 `http://localhost:8080/#/login`
3. 输入：

```
用户名：admin
密码：  Demo123456
```

4. 点 **「登录」** 按钮

### 你应该看到

- 右上角变成你的昵称「系统管理员」+ 一个下拉菜单
- 页面提示"登录成功"
- 地址栏跳到首页

### 4.3 确认数据都在

点顶部导航的 **「课程库」**：

```
http://localhost:8080/#/courses
```

### 你应该看到 5 门课程

| 课程 | 授课教师 | 资料数 |
|---|---|---|
| 数据结构与算法 | 张老师 | 0 |
| 编译原理 | 李老师 | 0 |
| 操作系统 | 王老师 | 0 |
| 大气科学导论 | 陈老师 | 0 |
| 竞赛与创新创业指导 | 陈老师 | 3 |

再点 **「资料库」**：

```
http://localhost:8080/#/resources
```

### 你应该看到 3 份资料

每张卡片上有标题、类型标签（PDF / PPTX）、可信度评分 **60.75**、下载次数。

> 如果课程数是 0 或课程里没有「竞赛与创新创业指导」，
> 说明数据库还是旧版本，去 ① 册第 8 节重新初始化。

## 5. 三个"健康检查"地址（收藏起来）

| 地址 | 是什么 | 用来干什么 |
|---|---|---|
| `http://localhost:8080/api/health` | 健康检查接口 | 返回 JSON 就说明后端活着 |
| `http://localhost:8080/doc.html` | Knife4j 接口文档 | 看所有接口，还能在线试调 |
| `http://localhost:8080/druid` | Druid 数据库监控 | 看 SQL 执行情况、连接池状态 |

`/api/health` 正常返回长这样：

```json
{
  "code": 0,
  "message": "服务运行正常",
  "data": {
    "status": "UP",
    "application": "coursehub",
    "profile": "dev",
    "serverTime": "2026-10-17 21:35:22",
    "javaVersion": "11.0.5"
  }
}
```

Druid 监控页要登录：用户名 `admin`，密码 `admin`（这个跟网站账号无关，是监控页自己的）。

## 6. 日常启动 / 关闭的标准流程

### 每次开机后要启动的东西

```
1. MySQL         ← 一般开机自启，用 netstat 确认一下就行
2. doubles click tools\start-redis.bat   ← 每次都要手动启动
3. 启动后端      ← IDEA 点绿三角，或双击 tools\start-backend.bat
4. 浏览器打开 localhost:8080
```

### 下班 / 关机前

```
1. 后端：Run 面板点红色 ⏹（或关掉 bat 窗口）
2. Redis：直接关那个黑窗口（数据本来就在内存里，关了就没了，这是正常的）
3. MySQL：不用管，它是服务
```

> Redis 关掉会丢什么？
> 只丢"缓存"和"未完成的分片上传进度"。
> 用户数据全在 MySQL 里，一条都不会少。

## 7. 启动阶段的常见报错（先自查，详细版见 ⑥ 册）

| 日志里的关键字 | 什么意思 | 去哪儿看 |
|---|---|---|
| `Web server failed to start. Port 8080 was already in use` | 8080 被占了 | ⑥ 册 F02 |
| `Unable to connect to Redis` / `Connection refused` | Redis 没启动 | ⑥ 册 F03 |
| `Access denied for user 'root'@'localhost'` | 数据库密码不对 | ⑥ 册 F04 |
| `Unknown database 'coursehub'` | 数据库还没建 | ① 册第 8 节 |
| `Table 'coursehub.sys_user' doesn't exist` | 建了库但没建表 | ① 册第 8 节 |
| `java: 无效的源发行版: 11` | IDEA 的 JDK 不是 11 | ① 册第 6.2 节 |
| 控制台一堆红色 `Cannot resolve symbol` | Maven 依赖没下载完 | ⑥ 册 F10 |
