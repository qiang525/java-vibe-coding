## 0. 先看全景：本册只有 4 个动作

| 动作 | 在哪操作 | 耗时 | 成功标志 |
|---|---|---|---|
| **① 确认 MySQL 在跑** | 命令行 | 1 分钟 | 看到 `LISTENING` 字样 |
| **② 启动 Redis** | 双击一个 bat | 1 分钟 | 窗口显示 `Ready to accept connections` |
| **③ 启动后端** | IDEA 或双击 bat | 2-5 分钟 | 日志显示 `Started CourseHubApplication` |
| **④ 浏览器打开并登录** | 浏览器 | 2 分钟 | 紫色界面 + 右上角显示昵称 |

**顺序不能乱**，因为后一个依赖前一个：

```
MySQL（存数据）  →  Redis（存缓存）  →  后端（干活）  →  浏览器（看界面）
   常驻服务           你要手动启动        你要手动启动        你
```

**耗时预期**：第一次（含等待 IDEA 索引）约 20-30 分钟；熟悉后 3 分钟。

### 顺便理解"单端口"这件事

很多人第一次做 Java Web 会困惑："前后端分离，不是要启动两个服务、开两个端口吗？"

本项目支持两种模式，第一次先用简单的：

| | 模式 A：单端口（本册用这个） | 模式 B：前后端分开（第 ④ 册讲） |
|---|---|---|
| 启动几个 | 只启动后端 | 后端 + 前端 Vite |
| 浏览器地址 | `http://localhost:8080` | `http://localhost:5173` |
| 适合 | 看效果、演示、交作业 | 改前端代码（改完自动刷新） |
| 原理 | 前端已打包成静态文件，放在 `backend/src/main/resources/static`，后端一起托管 | 前端跑自己的服务器，`/api` 请求转发给后端 |

> Spring Boot 默认把 `src/main/resources/static/` 当成网站根目录。
> 浏览器请求 `/` → 返回 `static/index.html`；请求 `/api/courses` → 才走 Java 代码。

## 1. 动作一：确认 MySQL 在跑

### 1.1 打开命令行

**方法（推荐）**：打开文件夹 `D:\桌面\Java项目AIGC` → 点顶部**地址栏** →
把里面的路径删掉 → 输入三个字母 `cmd` → 按**回车**。

弹出一个黑色窗口，显示：

```
Microsoft Windows [版本 10.0.19045.xxxx]
(c) Microsoft Corporation。保留所有权利。

D:\桌面\Java项目AIGC>
```

最后那个 `D:\桌面\Java项目AIGC>` 叫**提示符**，意思是"我现在站在这个文件夹，等你输入命令"。

### 1.2 输入命令

在提示符后面输入（可以鼠标右键粘贴）：

```
netstat -ano | findstr ":3306" | findstr "LISTENING"
```

按**回车**。

> 这条命令在问系统：**"3306 这个门牌号，现在有人占着吗？"**

### 1.3 判断结果

**✅ 情况 A：看到这样一行**（最后的数字可能不同）

```
  TCP    0.0.0.0:3306           0.0.0.0:0              LISTENING       7444
```

`LISTENING` = 正在监听 = **MySQL 活着**。最后那个 `7444` 是进程号，不用管。
→ **直接跳到第 2 节。**

**❌ 情况 B：什么都没输出**（光标换了一行，空的）

MySQL 没启动。按下面步骤启动：

1. 按 `Win + R`（同时按键盘左下角 Windows 键和 R 键）
2. 弹出「运行」小窗口，里面有个输入框
3. 输入 `services.msc` → 按**回车**
4. 弹出「服务」窗口，一长列列表
5. 在列表里找名字以 **MySQL** 开头的项（本机可能是 `MySQL80` 或 `MySQL82`）
6. **右键**它 → 点 **「启动」**
7. 等它的「状态」列变成 **「正在运行」**
8. 回命令行重新执行 1.2 的命令确认

> MySQL 一般**开机自启**，平时不用管。这一步只是"确认"，不是"每次都要启动"。

### ✅ 检查点 1

- [ ] 执行 `netstat -ano | findstr ":3306" | findstr "LISTENING"` 有输出

## 2. 动作二：启动 Redis

### 2.1 找文件并双击

1. 打开文件夹 `D:\桌面\Java项目AIGC\tools`
2. 找到 **`start-redis.bat`**
3. **双击它**

> 如果双击后窗口一闪就没，说明 bat 出问题，看 `06-故障排查.md` 的 **F01**。

### 2.2 窗口会显示什么

先出现一段中文说明（我写在脚本里的）：

```
============================================================
  启动 Redis（项目要用它做缓存和断点续传）
------------------------------------------------------------
  启动成功的样子：
    窗口刷出一堆日志，最后停在
        Ready to accept connections
  然后光标不动了 —— 这是正常的，它是个服务程序。

  这个黑色窗口千万不要关！
  关掉窗口 = Redis 停了 = 网站会报错。
============================================================
```

然后刷出一大段英文日志（版本号可能不同）：

```
                _._
           _.-``__ ''-._
      _.-``    `.  `_.  ''-._           Redis 8.x (00000000/0) 64 bit
  .-`` .-```.  ```\/    _.,_ ''-._
 (    '      ,       .-`  | `,    )     Running in standalone mode
 |`-._`-...-` __...-.``-._|'` _.-'|     Port: 6379
 |    `-._   `._    /     _.-'    |     PID: 12345
  `-._    `-._  `-./  _.-'    _.-'
[12345] 18 Oct 16:20:00.123 * Ready to accept connections
```

### 2.3 怎么算成功

**看到这一行就是成功**：

```
[12345] 18 Oct 16:20:00.123 * Ready to accept connections
```

翻译：`Ready to accept connections` = **"我准备好了，可以接客了"**。

**然后光标就不动了 —— 这是正常现象，不是卡死。**
Redis 是"服务程序"，启动完就停在那里等着，不会自己退出。

### 2.4 三件必须知道的事

| 要做 | 为什么 |
|---|---|
| **把窗口最小化，不要关** | 窗口在 = 服务在；窗口关 = 服务停 = 网站报错 |
| **不要在这个窗口里打字** | 打字会被当成 Redis 命令，可能把服务搞停 |
| **不要点右上角的 ×** | 同上 |

### 2.5 验证（可选但推荐）

再开**另一个**命令行窗口（原来那个别关），执行：

```
E:\java\redis\redis-cli.exe ping
```

**✅ 返回 `PONG`** = 通了。
**❌ 返回 `Could not connect to Redis at 127.0.0.1:6379: Connection refused`** = 没启动，回 2.1。

### ✅ 检查点 2

- [ ] `start-redis.bat` 窗口出现 `Ready to accept connections`
- [ ] 另一个命令行执行 `redis-cli.exe ping` 返回 `PONG`
- [ ] Redis 窗口还在（最小化了，但没关）

### 3.8 如果失败了，先看这三个地方

| 位置 | 看什么 |
|---|---|
| **Run 面板最后 20 行** | 真正的错误通常在**最后**，不是中间那些红字 |
| 搜 `Caused by:` | Java 异常一层层包，**最里面的 `Caused by` 才是根因** |
| 面板里按 `Ctrl + F` 搜 `ERROR` | 快速定位 |

**常见报错对照**：

| 日志里出现 | 去哪查 |
|---|---|
| `Port 8080 was already in use` | 第 ⑥ 册 F02 |
| `Unable to connect to Redis` | 第 ⑥ 册 F03（Redis 没起，回第 2 节） |
| `Access denied for user 'root'@'localhost'` | 第 ⑥ 册 F04（数据库密码不对） |
| `Unknown database 'coursehub'` | 第 ① 册第 8 节（还没建库） |
| `无效的源发行版: 11` | 第 ⑥ 册 F07（JDK 没设成 11） |
| 满屏 `Cannot resolve symbol` | 第 ⑥ 册 F10（Maven 没下载完） |

## 8. 日常启动 / 关闭的标准流程

### 8.1 每次开机后（MySQL 通常自启）

```
① 双击 tools\start-redis.bat      → 等 Ready to accept connections，窗口最小化
② 双击 tools\start-backend.bat    → 等 Started CourseHubApplication
   （或 IDEA 点绿三角）
③ 浏览器打开 localhost:8080
```

**熟悉后 30 秒内能完成。**

### 8.2 关机前

```
① 后端：IDEA 点红色 ⏹，或关掉 bat 窗口
② Redis：关掉那个黑窗口（数据在内存里，关了正常）
③ MySQL：不用管（它是系统服务）
```

### 8.3 只想重启后端（改完 Java 代码）

- IDEA：点 Run 面板的 **蓝色 ↻**（Rerun）
- bat：按 `Ctrl + C` 停掉，重新双击

### 8.4 三个窗口的关系

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ Redis 黑窗口     │   │ 后端（IDEA 或    │   │ 浏览器           │
│ 最小化，别关     │   │ bat 窗口）       │   │ 用完可以直接关    │
│                 │   │ 用完按 Ctrl+C    │   │                 │
└─────────────────┘   └─────────────────┘   └─────────────────┘
   ↑ 关了就报错          ↑ 关了网页打不开       ↑ 随便关
```
