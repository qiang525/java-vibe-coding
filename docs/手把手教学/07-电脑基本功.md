## 一、文件与文件夹：电脑是怎么"装东西"的

### 1.1 树形结构

电脑里的东西是一棵树，不是一张桌面：

```
这台电脑
├── C:  （系统盘）
│   ├── Windows
│   ├── Program Files
│   └── Users
│       └── liuwe          ← 你的用户文件夹（桌面、下载、文档都在这里）
│           ├── Desktop
│           ├── Downloads
│           └── Documents
├── D:  （你的第一个数据盘）
│   └── 桌面
│       └── Java项目AIGC    ← 本项目在这里
├── E:  （装了 Java、MySQL、Redis）
│   ├── java
│   └── 文件办公
└── F:  （备份、临时大文件）
```

**关键认知**：桌面不是一个"地方"，它只是 `C:\Users\liuwe\Desktop` 这个文件夹的**快捷显示**。

### 1.2 路径：怎么"说出"一个文件在哪

**路径 = 从盘符一路走到文件的地址**，用反斜杠 `\` 连接：

```
D:\桌面\Java项目AIGC\backend\pom.xml
└┬┘└┬┘└────┬────┘└──┬──┘└──┬──┘
盘符 文件夹   文件夹    文件夹  文件
```

读法：**"D 盘 → 桌面文件夹 → Java项目AIGC 文件夹 → backend 文件夹 → pom.xml 这个文件"**

三个必须掌握的说法：

| 说法 | 意思 | 例子 |
|---|---|---|
| **绝对路径** | 从盘符开始写完整 | `D:\桌面\Java项目AIGC\backend` |
| **相对路径** | 相对于"我现在在哪" | `backend\pom.xml`（我在 Java项目AIGC 里时） |
| **当前目录** | 命令行"站"的位置 | 命令行开头显示的 `D:\桌面\Java项目AIGC>` |

### 1.3 四个盘符分别干什么（这台电脑的实际情况）

| 盘 | 装了什么 | 规矩 |
|---|---|---|
| **C:** | Windows 系统、你的用户文件夹 | ⚠️ **不要往这里放项目和大文件**。C 盘满了系统会卡死 |
| **D:** | 你的桌面、本项目 | 放代码和文档 |
| **E:** | JDK、Maven、MySQL、Redis、`文件办公` 素材 | 放开发工具 |
| **F:** | 备份、临时大文件 | 放备份 |

> 为什么强调不往 C 盘放？因为 C 盘要装系统更新、虚拟内存、各种软件缓存。
> 只剩几 G 空间时 Windows 会开始卡、蓝屏。这是真实会发生的。

3. 点进 D 盘 → 桌面 → Java项目AIGC

5. 按 `Ctrl + L` 也能选中地址栏（这个快捷键很好用）

## 二、文件操作四件套（含两个新手常踩的坑）

### 2.1 四个基本动作

| 动作 | 怎么做 | 快捷键 |
|---|---|---|
| 新建文件夹 | 右键空白处 → 新建 → 文件夹 | `Ctrl + Shift + N` |
| 重命名 | 右键 → 重命名 | `F2` |
| 复制 / 移动 | 复制 `Ctrl+C` 粘贴 `Ctrl+V`；剪切 `Ctrl+X` | —— |
| 删除 | 右键 → 删除 | `Delete` |

### 2.2 坑一：`Shift + Delete` 不进回收站

| 操作 | 结果 |
|---|---|
| 按 `Delete` | 进回收站，能找回 |
| 按 `Shift + Delete` | **直接永久删除，找不回来** |

> 我这边的自动化操作有时会直接删文件。所以重要东西一律先备份，
> 备份脚本 `tools\backup-db.bat` 就是干这个的。

### 2.3 坑二：拖动 = 复制还是移动？

同一个盘内拖动 = **移动**；跨盘拖动（比如 C 盘拖到 D 盘）= **复制**。
不想搞错就**右键拖动**，松手时会让你选"复制/移动"。

## 三、压缩包：为什么别人的文件总是一个 .zip

### 3.1 是什么

**压缩包 = 把很多文件塞进一个盒子，顺便把体积压小。**

常见后缀：`.zip`（Windows 自带）、`.rar` / `.7z`（要装 WinRAR / 7-Zip）

### 3.2 关键动作：解压

**压缩包不能直接用。** 你要先把它"拆开"：

- **右键** `.zip` 文件 → **「全部解压缩」**（Windows 11 叫「全部提取」）
- 或者右键 → 用 7-Zip / WinRAR → 「解压到当前文件夹」

> ⚠️ 新手最常见的错误：**双击 .zip 打开，然后在里面直接双击运行程序**。
> 这样程序会被解压到临时目录，运行异常、数据丢失。
> **永远先解压，再从解压出来的文件夹里操作。**

### 3.3 你项目里的 .jar 和 .zip 不一样

| 后缀 | 是什么 | 能不能双击 |
|---|---|---|
| `.zip` | 普通压缩包 | 双击只能"看"，要先解压 |
| `.jar` | Java 的程序包（本质是 zip，但里面有程序） | 装好 Java 后双击能运行 |

## 四、命令行：那个黑窗口到底是什么

### 4.1 一句话

**命令行 = 用打字代替点鼠标来操作电脑。**

- 点鼠标：打开文件夹 → 找到文件 → 右键 → 删除
- 打字：`del 文件名` → 回车

看起来更麻烦，但**快、能批量、能自动化**。`tools\` 里那些 `.bat` 就是"把一串命令写下来，双击一次全执行"。

### 4.2 怎么打开（三种，推荐第一种）

**方式 A（最好用）**：进到某个文件夹 → **点地址栏 → 输入 `cmd` → 回车** → 命令行直接站在这个文件夹里

**方式 B**：`Win + R` → 输入 `cmd` → 回车（站在 C:\Users\liuwe）

**方式 C**：开始菜单搜 `cmd`

### 4.3 你会看到什么

```
Microsoft Windows [版本 10.0.19045.xxxx]
(c) Microsoft Corporation。保留所有权利。

C:\Users\liuwe>
```

最后那一行 `C:\Users\liuwe>` 是**提示符**：意思是"我现在站在这个目录，等你输入命令"。

### 4.4 只要记 5 个命令就够用

| 命令 | 作用 | 例子 |
|---|---|---|
| `dir` | 列出当前目录有什么 | `dir` |
| `cd 路径` | 切换目录（Change Directory） | `cd D:\桌面\Java项目AIGC` |
| `cd ..` | 回上一级 | `cd ..` |
| `cls` | 清屏（Clear Screen） | `cls` |
| `exit` | 关掉命令行 | `exit` |

### 4.5 三个必须知道的细节

**① 跨盘要加 `/d`**

```
cd D:\桌面\Java项目AIGC        ← 如果当前在 C 盘，这行只切"当前盘的目录"，不会真跳过去
cd /d D:\桌面\Java项目AIGC     ← 加 /d 才能跨盘跳转 ✅
```

**② 路径里有空格要加引号**

```
cd "E:\java\MySQL Server 8.2\bin"      ✅
cd E:\java\MySQL Server 8.2\bin        ❌ 会在 "MySQL" 后面断开
```

**③ 不能 Ctrl+V 粘贴**

黑窗口里：**右键 → 粘贴**，或者直接点鼠标右键（多数情况下直接粘贴）。

### 4.6 为什么"命令找不到"

你输入 `mysql` 却提示 `'mysql' 不是内部或外部命令` —— 不是没装，是**系统不知道去哪儿找这个程序**。

这就要说到 **环境变量 PATH**：

> **PATH = 一张"程序安装位置清单"。**
> 你敲 `java` 时，系统会拿着这张清单，一个文件夹一个文件夹地找有没有 `java.exe`。
> 找不到就报"不是内部或外部命令"。

所以修 Java 的命令行问题，本质就是"把 JDK 的 bin 目录加进 PATH"。
你项目里的 `tools\fix-java-path\run-fix.bat` 就是自动干这件事的。

### 🔬 现在试一下（5 分钟）

打开命令行，依次输入（每行回车）：

```
cd /d D:\桌面\Java项目AIGC
dir
cd backend
dir
cd ..
cls
```

**你应该看到**：`dir` 列出了文件清单，`cd ..` 之后又回到了上一级。
如果某一步报"系统找不到指定的路径"，说明你打错了字——**照抄，别凭记忆**。

## 五、进程与任务管理器

### 5.1 什么是进程

**进程 = 一个正在运行的程序。**

- 你双击 `redis-server.exe` → 系统创建一个进程
- 你用 IDEA 启动后端 → 系统创建一个 `java.exe` 进程
- 你关掉窗口 → 进程结束

> 程序是"菜谱"（存在硬盘上的文件），进程是"正在做的这道菜"（占用内存和 CPU）。
> **一个程序可以同时有多个进程**（比如开三个 QQ）。

### 5.2 怎么看

按 `Ctrl + Shift + Esc` → 任务管理器 → 「详细信息」标签。

你会看到一列 PID（进程号），这是系统给每个进程发的**唯一编号**。
后面的"杀进程"命令就是靠这个编号精确操作的。

### 5.3 为什么"关掉窗口"有时不等于"程序停了"

| 情况 | 关窗口后 |
|---|---|
| 普通程序（记事本、浏览器） | 进程结束 ✅ |
| 有托盘图标的（微信、QQ） | 进程还在后台 |
| 命令行启动的服务（Redis、后端） | 看你关的是哪个窗口 |
| 卡死的程序 | 窗口没了但进程还在 → **端口一直被占着** |

这就是"我明明关了，怎么还说端口被占用"的原因。

### 🔬 现在试一下（2 分钟）

1. `Ctrl + Shift + Esc` 打开任务管理器
2. 找 `node.exe` 或 `java.exe`（可能没有，正常）
3. 右键任意一个不重要的程序 → 「结束任务」→ 看它是不是真的关了

## 六、端口：为什么老是"8080 被占用"

### 6.1 一句话

**端口 = 一台电脑上，不同服务的"门牌号"。**

一台电脑只有一个 IP 地址（相当于一栋楼），但可以同时跑很多服务。
为了区分"这个请求是找谁的"，每个服务占一个端口号：

```
你的电脑（localhost = 127.0.0.1）
├── 3306  ← MySQL 在这扇门后面
├── 6379  ← Redis 在这扇门后面
├── 8080  ← 你的网站后端在这扇门后面
└── 5173  ← 前端开发服务器在这扇门后面
```

浏览器访问 `http://localhost:8080` 的真实意思是：
**"敲本机 8080 号门，把网页给我"**。

### 6.2 为什么会"被占用"

**一个门牌号同时只能有一个服务。**

你之前启动过后端但没关干净，8080 这扇门还开着 →
再启动一次，新服务发现门被占了 → 报错
`Port 8080 was already in use`。

解决办法就是：找到占着门的进程 → 结束它（第 5 节的方法）。

### 6.3 三个常用命令（都在命令行里跑）

**查谁占着 8080**：

```
netstat -ano | findstr ":8080"
```

输出最后那个数字就是 PID。

**看这个 PID 是什么程序**：

```
tasklist | findstr "17532"
```

**杀掉它**：

```
taskkill /F /PID 17532
```

> 记不住没关系，`06-故障排查.md` 的 F02 有完整步骤，照抄就行。

### 🔬 现在试一下（3 分钟）

```
netstat -ano | findstr ":3306"
```

你应该能看到 MySQL 在监听。**这就是"用命令行观察系统正在发生什么"的感觉**，以后排错全靠它。

## 七、浏览器 F12：前端排错的唯一入口

### 7.1 怎么打开

在网页上按 **`F12`**（或右键 → 检查）。

会弹出开发者工具，通常出现在右边或下边。

### 7.2 只需要认识 3 个标签

| 标签 | 中文 | 看什么 |
|---|---|---|
| **Console** | 控制台 | **红色报错**。页面白屏、按钮没反应，先看这里 |
| **Network** | 网络 | 每个请求的 URL、状态码、返回内容。接口通不通看这里 |
| **Application** | 应用 | `Local Storage` 里存着登录 token |

### 7.3 用 Network 看懂"一次请求"

这是最有用的技能。操作步骤：

1. 打开 `http://localhost:8080`，按 `F12`，切到 `Network`
2. 勾选 `Fetch/XHR`（只看接口请求，过滤掉图片）
3. 在网页上点「登录」，输入账号密码，点登录
4. Network 面板会多出一行 `login`
5. 点那一行，右侧看三块：

| 区域 | 看什么 |
|---|---|
| **Headers** | 请求地址、方法（POST）、状态码（200） |
| **Payload** | 你发过去的数据（账号密码） |
| **Response** | 后端返回的 JSON（token、昵称） |

**看懂这个，你就理解了"前后端"的全部秘密**：前端发一个请求，后端返回一个 JSON。

### 7.4 状态码速记

| 码 | 意思 |
|---|---|
| 200 | 成功 |
| 401 | 没登录 / 登录过期 |
| 403 | 登录了但没权限 |
| 404 | 地址不存在 |
| 500 | 后端代码报错了（去 IDEA 的 Run 面板看） |

### 🔬 现在试一下（5 分钟，需要后端在跑）

1. 打开 `http://localhost:8080`
2. `F12` → `Network` → 点 `Fetch/XHR`
3. 点「登录」，账号 `admin`，密码 `Demo123456`
4. 找到 `login` 请求，看 `Response` 里的 `token`
5. 再切到 `Application` → `Local Storage` → 看 `token` 是不是存进去了

## 八、环境变量：那个让新手崩溃的 PATH

### 8.1 一句话

**环境变量 = 系统记着的一堆"小纸条"，程序启动时会去读。**

最常用的是 `PATH`（第 4.6 节讲过）：告诉系统"去哪儿找程序"。

其次是各种**配置开关**，比如：

| 变量 | 作用 | 本项目里 |
|---|---|---|
| `JAVA_HOME` | 告诉工具 JDK 装在哪 | `E:\java\jdk11` |
| `MYSQL_PWD` | 临时传数据库密码 | 验证脚本用它，避免写死密码 |
| `SERVER__PORT` | 改 Spring Boot 的端口 | ⚠️ IDEA 有时会自动注入这个，导致端口变成 49987 |

### 8.2 怎么看

命令行里：

```
echo %JAVA_HOME%
```

会打印出变量的值。如果打印出 `%JAVA_HOME%` 本身，说明这个变量**没设置**。

### 8.3 怎么改

`Win + R` → 输入 `sysdm.cpl` → 「高级」→ 「环境变量」→
上半部分是"用户变量"，下半部分是"系统变量"。

> ⚠️ 改完**必须关掉所有命令行窗口重开**，新值才生效。
> 这是 90% 的"我改了怎么没用"的原因。

## 附：这套东西为什么学校不教

因为**它们是"工具的使用方法"，不是"知识点"**。

学校课程要考核、要打分，所以教的是能出题的东西：变量、循环、排序算法。
而"怎么打开命令行""端口被占用怎么办"没法出题，就被跳过了。

但工作里 80% 的时间花在这些事上。
你现在补的，正是那被跳过的 80%。
