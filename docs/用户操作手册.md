## 一、第一次使用：启动项目

### 准备：确认三样东西都装好了

| 需要的东西 | 在哪 | 怎么确认 |
|---|---|---|
| JDK 11 | `E:\java\jdk11` | 文件夹存在即可 |
| Maven | `E:\java\apache-maven-3.9.16` | 文件夹存在即可 |
| MySQL 8 | `E:\java\MySQL` | 服务在运行 |
| Redis | `E:\java\redis` | 见下一步 |
| Node.js | `E:\node.js` | 文件夹存在即可 |

### 先选一种启动方式

本项目是**前后端分离**的，所以有两条路可以走：

| 方式 | 要启动几个东西 | 适合什么场景 | 网页地址 |
|---|---|---|---|
| **方式 A：前后端分开** | Redis + 后端 + 前端 | **改前端代码**（改完自动刷新，不用重新打包） | `http://localhost:5173` |
| **方式 B：只启后端** | Redis + 后端 | **只想看效果 / 交作业 / 演示** | `http://localhost:8080` |

> 💡 为什么分两种？
> "前后端分离"意味着前端和后端是两个独立的程序。
> 开发时分开跑最方便（前端有热更新）；如果只是想打开看看，
> 把前端打包进后端，只启一个服务就够了 —— 这就是方式 B。

**第一次用建议先走方式 A**，熟悉之后再试方式 B。

---

### 启动步骤 —— 方式 A（前后端分开）

#### 第 1 步：启动 Redis

**双击** `E:\java\redis\start.bat`

会出现一个黑色窗口，显示一些中文提示后**停住不动**。

> ✅ **窗口停住是正常的！** Redis 是服务器程序，就是要一直运行。
> ❌ 不要关掉这个窗口，也不要以为它卡死了。

#### 第 2 步：验证 Redis 是否启动成功

**双击** `E:\java\redis\check.bat`

应该看到：

```
[状态] 运行中
PONG
redis_version:8.10.2
```

看到 `PONG` 就说明 Redis 正常。这个窗口会自动关闭。

#### 第 3 步：启动后端

打开一个命令行窗口（Win+R 输入 `cmd` 回车），依次输入：

```cmd
cd D:\桌面\Java项目AIGC\backend
set JAVA_HOME=E:\java\jdk11
E:\java\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run
```

**等待大约 30 秒**，直到看到这一行：

```
Started CourseHubApplication in 2.6 seconds
```

> ✅ 看到这句就是成功了。
> ❌ **别关这个窗口**，关了后端就停了。

#### 第 4 步：启动前端

**再开一个新窗口**（原来的不要关），输入：

```cmd
cd D:\桌面\Java项目AIGC\frontend
E:\node.js\npm.cmd run dev
```

等待大约 5 秒，看到：

```
  ➜  Local:   http://localhost:5173/
```

#### 第 5 步：打开浏览器

在浏览器地址栏输入：

```
http://localhost:5173
```

看到 CourseHub 首页就成功了。

> **此时应该看到**：紫色渐变 logo + "CourseHub 课程资料协作平台" + 一个**绿色的状态卡片**写着"后端连接正常"。

---

### 启动步骤 —— 方式 B（只启后端，浏览器打开 8080）

**前提**：先执行过一次"打包"（把前端打包进后端）。

#### 第 0 步（只需做一次）：把前端打包进后端

**双击** `D:\桌面\Java项目AIGC\frontend\build-to-backend.bat`

会看到它做三件事：

```
[1/3] 正在构建前端（npm run build）...
[2/3] 正在复制到后端静态目录...
[3/3] 完成！
```

> ⚠️ 过程中会出现 `✓`、`│` 之类的符号显示成乱码 ——
> 那是 cmd 窗口编码问题，**不影响构建结果**，忽略即可。
>
> 📌 **改了前端代码之后要重新跑一次**，否则 8080 上还是旧页面。

#### 第 1 步：启动 Redis

双击 `E:\java\redis\start.bat`

#### 第 2 步：启动后端

```cmd
cd D:\桌面\Java项目AIGC\backend
set JAVA_HOME=E:\java\jdk11
E:\java\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run
```

#### 第 3 步：打开浏览器

```
http://localhost:8080
```

看到首页就成功了。

> **和方式 A 的区别**：不用再开第二个窗口启动前端；网页地址是 8080 而不是 5173。
> 代价是没有热更新 —— 改了前端代码要重新打包。

> 📌 **接口文档也在 8080**：`http://localhost:8080/doc.html`

---

### 启动步骤 —— 在 IDEA 里启动（推荐写代码时用）

用 IDEA 启动更舒服：能打断点、看日志、看变量。

**第一次配置（只需做一次）**：

```
1. 打开 IDEA → File → Open
2. 选择目录：D:\桌面\Java项目AIGC\backend      ← 注意是 backend，不是项目根目录
3. 弹出 "Trust Project?" 点 Trust
4. 右下角提示导入 Maven 项目 → 点 "Load Maven Project"
   （或点右侧 Maven 面板的刷新按钮）
5. 等依赖下载完（第一次几分钟，之后很快）
```

**每次启动**：

```
1. 先双击 E:\java\redis\start.bat   ← Redis 必须先起来
2. 在 IDEA 左侧展开到：
     backend / src / main / java / com.nnuist.coursehub / CourseHubApplication
3. 双击打开这个文件，点代码左侧行号旁的绿色 ▶ 三角
   （或右键文件 → Run 'CourseHubApplication'）
4. 下方 Run 面板出现这一行就是成功：
     Started CourseHubApplication in x.x seconds
5. 浏览器打开 http://localhost:8080
```

**如果报"数据库连接失败"**：
检查 `backend/src/main/resources/application-local.yml` 是否存在、密码对不对。

> 📌 **IDEA 里也能只启后端看网页**：
> 只要先跑过一次 `build-to-backend.bat`，IDEA 里启动后 8080 就是完整网页。

**想改前端代码**：IDEA 里启动后端，另开命令行跑 `npm run dev`，
浏览器用 `http://localhost:5173`（方式 A）。

---

### 关闭项目

用完之后：

1. 前端窗口：按 `Ctrl + C`，输入 `Y` 回车
2. 后端窗口：按 `Ctrl + C`，输入 `Y` 回车
3. **双击** `E:\java\redis\stop.bat` 停止 Redis
   （方式 B 只有一个后端窗口，按 `Ctrl + C` 停掉即可）

> 📌 IDEA 里停止：点下方 Run 面板的红色方块 ⏹

## 三、完整使用流程（跟着做一遍）

下面是一条完整的链路，**建议按顺序走一遍**，全部走通说明项目完全正常。

### 阶段一：注册与登录

```
① 打开 http://localhost:5173
② 点右上角「登录」按钮
③ 在登录卡片上点「注册」标签页
④ 填写：账号 / 密码 / 昵称
⑤ 点「注册」按钮 → 提示"注册成功，请登录"
⑥ 自动切回「登录」标签页，账号已填好
⑦ 输入密码，点「登录」→ 提示"登录成功"
⑧ 回到首页，右上角变成你的昵称
```

> 💡 也可以用管理员账号直接登录：`admin` / `admin123`

### 阶段二：创建一门课程

```
① 点顶部「课程」
② 点右上角「新建课程」按钮
③ 弹出对话框，填写：
     课程名称：数据结构与算法        （必填）
     课程编号：DS-204
     所属学院：选一个
     授课教师：张老师
     开课学期：2026-2027-1
     学分：3.5
     课程简介：讲授线性表、树、图等内容
④ 点「确定创建」
⑤ 列表刷新，新课程出现在最前面
⑥ 列表里能看到"成员 1 · 资料 0"（创建者自动成为成员）
```

### 阶段三：上传第一份资料

```
① 点刚创建的那门课程，进入课程详情页
② 点右上角「上传资料」按钮
③ 弹出上传对话框，进入「选择文件」步骤
④ 点虚线框，或直接把文件拖进去
     （建议先用小文件，比如几 MB 的 PDF）
⑤ 自动进入「上传文件」步骤，显示进度条：
     正在计算文件指纹… → 上传分片 3/10 → 合并校验… → 上传完成
⑥ 自动进入「填写信息」步骤：
     资料标题：已自动用文件名填好，可以改
     资料类型：选「讲义」
     可见范围：选「全平台公开」
     资料描述：写几句说明
⑦ 点「发布资料」→ 提示"资料发布成功"
⑧ 对话框关闭，课程详情页的资料列表出现了这份资料
```

### 阶段四：浏览与搜索

```
① 点顶部「资料库」
② 在搜索框输入「数据结构」，点「搜索」
③ 看到结果列表，每条的右下角显示"相关度 0.093"
④ 点任意一条资料 → 进入资料详情页
⑤ 点「下载文件」→ 浏览器开始下载
⑥ 回到资料库，点「热门搜索」里任意一个标签 → 直接搜索
```

### 阶段五：协作互动（收藏 / 评论 / 版本 / 举报）

现在这些操作**都有界面了**，不用再去接口文档。

```
① 收藏
   → 在资料详情页点「收藏」按钮，按钮变金色 = 收藏成功
   → 右上角头像 → 「我的收藏」，能看到刚收藏的资料

② 评论
   → 在资料详情页往下拉，点「讨论区」标签页
   → 在输入框写一句话，可以选「讨论 / 纠错 / 补充」
   → 点「发表评论」
   → 点某条评论下的「回复」，可以就着这条继续聊

③ 版本
   → 点「版本历史」标签页，能看到 v1
   → 点右上角「上传新版本」，选另一个文件、填变更说明
   → 提交后列表里会出现 v2，并且标着「当前版本」
   → 想撤销？点 v1 那行的「回滚到此版本」
     （注意：回滚会生成 v3，而不是删掉 v2 —— 历史永远保留）

④ 举报
   → 在资料详情页点「举报」，选原因、写说明、提交
   → 换成 admin 登录，右上角头像 → 「举报处理」
   → 找到那条举报，点「处理该举报」，选「属实」或「驳回」
```

> 📌 上面每一步都有对应的成对设计：
> 「上传新版本 ↔ 回滚」「举报 ↔ 处理」「收藏 ↔ 我的收藏」，
> 走一遍就能体会到**一个完整功能的闭环长什么样**。

## 四、各项操作详细步骤

### 4.1 注册账号

| 步骤 | 操作 |
|---|---|
| 1 | 点右上角「**登录**」 |
| 2 | 点「**注册**」标签页 |
| 3 | 输入账号（3-50 字符，建议用学号） |
| 4 | 输入密码（6-50 字符） |
| 5 | 输入昵称 |
| 6 | 选所属学院（可选） |
| 7 | 点「**注册**」 |

**注册失败对照表**

| 提示 | 原因 |
|---|---|
| 该账号已被注册 | 换一个账号 |
| 账号长度须为 3-50 个字符 | 太短或太长 |
| 密码长度须为 6-50 个字符 | 太短 |

### 4.2 登录

| 步骤 | 操作 |
|---|---|
| 1 | 点右上角「**登录**」 |
| 2 | 输入账号和密码 |
| 3 | 点「**登 录**」按钮（也可以直接在密码框按回车） |

**登录失败对照表**

| 提示 | 原因 |
|---|---|
| 账号或密码错误 | 账号不存在 **或** 密码错（故意不区分，防账号探测） |
| 账号已被禁用 | 账号被管理员封了 |

### 4.3 退出登录

| 步骤 | 操作 |
|---|---|
| 1 | 点右上角**你的头像/昵称** |
| 2 | 下拉菜单里点「**退出登录**」 |

### 4.4 创建课程

1. 顶部「**课程**」→ 右上角「**新建课程**」
2. 填表单，只有**课程名称**是必填的
3. 点「**确定创建**」

> ⚠️ **如果提示"课程名称不能为空"**：说明名称为空，填上即可。

### 4.5 加入课程

1. 顶部「**课程**」
2. 找到目标课程卡片
3. 点卡片上的「**加入课程**」按钮（注意：点按钮不会跳转到详情页）

> ⚠️ **未登录时会提示"请先登录后再加入课程"**，并跳转到登录页。
> 登录后会自动跳回课程库。

### 4.6 上传资料（重点）

#### 入口有两个

| 入口 | 位置 |
|---|---|
| 入口 A | 课程详情页 → 右上角「**上传资料**」 |
| 入口 B | （未来会加到资料库页） |

#### 三个步骤

**第 1 步：选择文件**

- 方式一：点虚框 → 弹出系统文件选择框 → 选中文件 → 点"打开"
- 方式二：把文件从文件夹**直接拖进**虚框

**第 2 步：自动上传**

进度条会依次经过：

| 阶段 | 说明 | 进度区间 |
|---|---|---|
| 正在计算文件指纹 | 前端算整个文件的 MD5 | 0-20% |
| 检查服务端是否已有该文件 | 判断能否秒传 | 22% |
| 上传分片 | 5MB 一片依次上传 | 25-92% |
| 正在合并分片并校验完整性 | 服务端拼接并做 MD5 复验 | 94-100% |

> 💡 **如果显示"秒传成功"**：说明服务端已经有完全相同的文件，直接完成了。
> 💡 **如果中途失败**：重新上传同一个文件，**已传的分片不会重传**（断点续传）。

**第 3 步：填写信息**

| 字段 | 说明 |
|---|---|
| 资料标题 | 已自动填好（取文件名去掉扩展名），可以改 |
| 资料类型 | 讲义 / 教材 / 真题 / 笔记 / 作业 / 视频 / 其他 |
| **可见范围** | 见下方说明 ⬇️ |
| 资料描述 | 选填，建议写清楚内容 |

**可见范围怎么选**（重要）

| 选项 | 谁能看到 | 什么时候用 |
|---|---|---|
| **全平台公开** | 所有人，包括没登录的 | 通用的课件、真题 |
| **仅本课程** | 只有本课程成员和课程负责人 | 课程内部资料 |
| **仅自己可见** | 只有你自己 | 个人笔记、草稿 |

选完后点「**发布资料**」。

### 4.7 搜索资料

**方式一：关键词搜索**

1. 顶部「**资料库**」
2. 搜索框输入关键词（如"数据结构"）
3. 点「**搜索**」或按回车

**方式二：点热词**

热门搜索区域的标签，点一下就直接搜。

**方式三：按类型/课程筛选**

用下面的「全部类型」「全部课程」下拉框筛选。

> 💡 **搜索结果按"相关度"排序**，相关度显示在每条资料的右下角。
> 相关度越高说明匹配越好。

### 4.8 下载资料

1. 进入资料详情页（点资料卡片）
2. 点「**下载文件**」按钮
3. 浏览器开始下载，文件名保持原样（中文也正常）

> ⚠️ **必须先登录才能下载。**

### 4.9 修改资料信息

1. 进入资料详情页
2. 点「**编辑信息**」按钮（只有上传者/课程负责人/管理员能看到这个按钮）
3. 修改标题 / 类型 / 可见范围 / 描述
4. 点「**保存**」

### 4.10 删除资料

1. 进入资料详情页
2. 点「**删除资料**」按钮（红色）
3. 弹出确认框，点「**确定删除**」

> ⚠️ **删除是"逻辑删除"**：数据还在数据库里，只是标记为已删除，
> 列表里看不到。管理员可以恢复。

### 4.11 收藏 / 取消收藏资料

1. 进入资料详情页
2. 点「**收藏**」按钮
3. 按钮会变成金色「**已收藏**」，同时上方数据条里的"收藏"数字 +1
4. 再点一次即可**取消收藏**

**去哪里看我收藏的东西**：

```
右上角头像 → 「我的收藏」
```

在「我的收藏」页面里，可以：

- 点卡片直接跳到资料详情
- 点「**取消收藏**」把资料移出收藏夹

### 4.12 发表评论 / 回复（讨论区）

1. 进入资料详情页，往下找到「**讨论区**」标签页，点它
2. 在输入框写内容
3. 左侧三个按钮选一种类型：
   - **讨论** —— 普通交流
   - **纠错** —— 指出资料里的错误（列表里会显示红色"纠错"标签）
   - **补充** —— 补充内容（显示橙色"补充"标签）
4. 点「**发表评论**」

**回复某条评论**：

1. 找到想回复的那条评论
2. 点这条评论下面的「**回复**」
3. 下方会展开输入框，写完后点「**回复**」

**删除自己的评论**：

点评论下面的「**删除**」（只有自己的评论或管理员才有这个按钮）。

### 4.13 上传新版本 / 回滚（版本历史）

**上传新版本**（资料的"迭代"）：

1. 进入资料详情页 → 点「**版本历史**」标签页
2. 点右上角「**上传新版本**」
3. 选文件（或拖拽）→ 选完后填「变更说明」
4. 点「**上传并生成新版本**」
5. 上传过程会显示进度条；完成后列表里多出一条 v2

**下载历史版本**：

在任意一条版本右侧点「**下载**」，拿到的是**那个版本当时的文件**。

**回滚**（把内容退回某个旧版本）：

1. 在不是"当前版本"的那一行，点「**回滚到此版本**」
2. 确认后，会**生成一个新版本**（例如 v3），内容取自 v1

> ⚠️ **回滚不是"删掉中间的版本"**。
> 它是以旧版本的内容**新增**一条记录，所以历史链路完整保留，
> 你能清楚地看到"什么时候改的、什么时候回滚的"。
> 新生成的版本会带一个橙色「回滚生成」标签。

### 4.14 举报资料 / 评论

1. **举报资料**：资料详情页 → 点「**举报**」
2. **举报评论**：讨论区里某条评论下的「**举报**」
3. 选「举报原因」（侵权盗版 / 内容错误 / 冒充官方 / 广告推广 / 垃圾内容 / 其他）
4. 填「补充说明」（选填，最多 500 字）
5. 点「**提交举报**」

> 同一个对象在管理员处理之前**只能举报一次**（再提交会提示"你已经举报过了"），
> 这是为了避免刷举报。

### 4.15 处理举报（仅管理员）

1. 用管理员账号登录（`admin / admin123`）
2. 右上角头像 → 「**举报处理**」
3. 顶部可以按状态筛选：**全部 / 待处理 / 已处理 / 已驳回**
4. 找到目标举报，点「**处理该举报**」
5. 选结论：
   - **属实，已处理**
   - **不属实，驳回**
6. 填「处理说明」（选填），点「**确认处理**」

> 如果被举报的是资料，可以点「查看被举报资料」直接跳过去核实。
> 非管理员访问这个页面会看到"需要管理员权限"的提示。

### 4.16 使用接口文档调试（进阶）

这是**不用写前端界面也能操作所有功能**的方式：

1. 浏览器打开 `http://localhost:8080/doc.html`
2. 左侧展开「**01-认证与用户**」→「**用户登录**」
3. 点右侧「**调试**」标签
4. 填 `{"username":"admin","password":"admin123"}`
5. 点「**发送**」
6. **复制响应里的 `token` 值**（很长的一串）
7. 点右上角「**文档管理**」→「**全局参数设置**」
8. 点「添加」，参数名填 `Authorization`，值填 `Bearer <刚才复制的token>`
   （注意 `Bearer` 后面**有一个空格**）
9. 点「确定」

**完成！** 现在所有需要登录的接口都能直接调试了。

## 五、常见问题排查

### 5.1 页面打不开

| 现象 | 检查 |
|---|---|
| 浏览器显示"无法访问" | 前端窗口是不是关了？重新 `npm run dev` |
| 页面能开但**状态卡片是红色** | 后端没起来，回去检查第 3 步 |
| 页面一片空白 | 按 F12 打开控制台看报错 |

### 5.2 登录不上

| 现象 | 解决 |
|---|---|
| 提示"账号或密码错误" | 用 `admin` / `admin123` 试试；或重新注册 |
| 登录后立刻又跳回登录页 | 后端可能重启了导致 Token 失效，重新登录 |

### 5.3 上传失败

| 提示 | 原因 | 解决 |
|---|---|---|
| 不支持的文件类型 | 扩展名不在白名单 | 只支持 PDF/Word/PPT/Excel/图片/压缩包 |
| 文件内容与扩展名不符 | 文件被改过后缀名 | 用正常文件 |
| 单个文件不能超过 500 MB | 文件太大 | 压缩后再传 |
| 上传失败，请重试 | 网络或后端问题 | 重新上传（已传的分片会保留） |

### 5.4 下载失败

| 现象 | 原因 |
|---|---|
| 提示"请先登录后再下载" | 未登录 |
| 下载下来是乱码文本 | 可能下载的是错误响应，检查后端日志 |

### 5.5 中文乱码

如果命令行窗口里中文显示成乱码 —— **这是正常的**，因为命令行的编码和文件编码不一致。
浏览器里显示是正常的。

### 5.6 想看看后端到底在干什么

打开后端窗口，会看到滚动的日志，例如：

```
登录成功 | userId=1 | username=admin | role=ADMIN
文件上传成功 | fileId=5 | name=数据结构.pdf | size=2621440
秒传命中 | hash=abc123... | fileId=5
发布资料 | resourceId=3 | courseId=1 | title=第二章 线性表
```

**每一条日志都对应你在界面上的一个动作**，对应着看很容易理解。

## 六、给不同角色的使用建议

```
登录 → 资料库搜索 → 找到资料 → 下载

```
