## 一、第一次使用：启动项目

### 准备：确认三样东西都装好了

| 需要的东西 | 在哪 | 怎么确认 |
|---|---|---|
| JDK 11 | `E:\java\jdk11` | 文件夹存在即可 |
| Maven | `E:\java\apache-maven-3.9.16` | 文件夹存在即可 |
| MySQL 8 | `E:\java\MySQL` | 服务在运行 |
| Redis | `E:\java\redis` | 见下一步 |
| Node.js | `E:\node.js` | 文件夹存在即可 |

### 启动步骤（每次使用都要做）

#### 第 1 步：启动 Redis

**双击** `E:\java\redis\start.bat`

会出现一个黑色窗口，显示一些中文提示后**停住不动**。

> ✅ **窗口停住是正常的！** Redis 是服务器程序，就是要一直运行。
> ❌ 不要关掉这个窗口，也不要以为它卡死了。

#### 第 2 步：验证 Redis 是否启动成功

**双击** `E:\java\redis\check.bat`

应该看到：

```
[状态] 运行中
PONG
redis_version:8.10.2
```

看到 `PONG` 就说明 Redis 正常。这个窗口会自动关闭。

#### 第 3 步：启动后端

打开一个命令行窗口（Win+R 输入 `cmd` 回车），依次输入：

```cmd
cd D:\桌面\Java项目AIGC\backend
set JAVA_HOME=E:\java\jdk11
E:\java\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run
```

**等待大约 30 秒**，直到看到这一行：

```
Started CourseHubApplication in 2.6 seconds
```

> ✅ 看到这句就是成功了。
> ❌ **别关这个窗口**，关了后端就停了。

#### 第 4 步：启动前端

**再开一个新窗口**（原来的不要关），输入：

```cmd
cd D:\桌面\Java项目AIGC\frontend
E:\node.js\npm.cmd run dev
```

等待大约 5 秒，看到：

```
  ➜  Local:   http://localhost:5173/
```

#### 第 5 步：打开浏览器

在浏览器地址栏输入：

```
http://localhost:5173
```

看到 CourseHub 首页就成功了。

> **此时应该看到**：紫色渐变 logo + "CourseHub 课程资料协作平台" + 一个**绿色的状态卡片**写着"后端连接正常"。

### 关闭项目

用完之后：

1. 前端窗口：按 `Ctrl + C`，输入 `Y` 回车
2. 后端窗口：按 `Ctrl + C`，输入 `Y` 回车
3. **双击** `E:\java\redis\stop.bat` 停止 Redis

## 三、完整使用流程（跟着做一遍）

下面是一条完整的链路，**建议按顺序走一遍**，全部走通说明项目完全正常。

### 阶段一：注册与登录

```
① 打开 http://localhost:5173
② 点右上角「登录」按钮
③ 在登录卡片上点「注册」标签页
④ 填写：账号 / 密码 / 昵称
⑤ 点「注册」按钮 → 提示"注册成功，请登录"
⑥ 自动切回「登录」标签页，账号已填好
⑦ 输入密码，点「登录」→ 提示"登录成功"
⑧ 回到首页，右上角变成你的昵称
```

> 💡 也可以用管理员账号直接登录：`admin` / `admin123`

### 阶段二：创建一门课程

```
① 点顶部「课程」
② 点右上角「新建课程」按钮
③ 弹出对话框，填写：
     课程名称：数据结构与算法        （必填）
     课程编号：DS-204
     所属学院：选一个
     授课教师：张老师
     开课学期：2026-2027-1
     学分：3.5
     课程简介：讲授线性表、树、图等内容
④ 点「确定创建」
⑤ 列表刷新，新课程出现在最前面
⑥ 列表里能看到"成员 1 · 资料 0"（创建者自动成为成员）
```

### 阶段三：上传第一份资料

```
① 点刚创建的那门课程，进入课程详情页
② 点右上角「上传资料」按钮
③ 弹出上传对话框，进入「选择文件」步骤
④ 点虚线框，或直接把文件拖进去
     （建议先用小文件，比如几 MB 的 PDF）
⑤ 自动进入「上传文件」步骤，显示进度条：
     正在计算文件指纹… → 上传分片 3/10 → 合并校验… → 上传完成
⑥ 自动进入「填写信息」步骤：
     资料标题：已自动用文件名填好，可以改
     资料类型：选「讲义」
     可见范围：选「全平台公开」
     资料描述：写几句说明
⑦ 点「发布资料」→ 提示"资料发布成功"
⑧ 对话框关闭，课程详情页的资料列表出现了这份资料
```

### 阶段四：浏览与搜索

```
① 点顶部「资料库」
② 在搜索框输入「数据结构」，点「搜索」
③ 看到结果列表，每条的右下角显示"相关度 0.093"
④ 点任意一条资料 → 进入资料详情页
⑤ 点「下载文件」→ 浏览器开始下载
⑥ 回到资料库，点「热门搜索」里任意一个标签 → 直接搜索
```

### 阶段五：协作互动

```
① 在资料详情页（当前还没有评论功能入口，用接口文档操作）
② 打开 http://localhost:8080/doc.html
③ 找到「07-评论」→ 发表评论
④ 填 resourceId 和 content，点发送
⑤ 回到资料详情页刷新，可以看到评论数 +1
```

> 📌 评论/收藏/举报的**前端界面还比较简单**（M3 主要实现了后端接口），
> 完整操作可以通过 `doc.html` 接口文档直接调试。

## 四、各项操作详细步骤

### 4.1 注册账号

| 步骤 | 操作 |
|---|---|
| 1 | 点右上角「**登录**」 |
| 2 | 点「**注册**」标签页 |
| 3 | 输入账号（3-50 字符，建议用学号） |
| 4 | 输入密码（6-50 字符） |
| 5 | 输入昵称 |
| 6 | 选所属学院（可选） |
| 7 | 点「**注册**」 |

**注册失败对照表**

| 提示 | 原因 |
|---|---|
| 该账号已被注册 | 换一个账号 |
| 账号长度须为 3-50 个字符 | 太短或太长 |
| 密码长度须为 6-50 个字符 | 太短 |

### 4.2 登录

| 步骤 | 操作 |
|---|---|
| 1 | 点右上角「**登录**」 |
| 2 | 输入账号和密码 |
| 3 | 点「**登 录**」按钮（也可以直接在密码框按回车） |

**登录失败对照表**

| 提示 | 原因 |
|---|---|
| 账号或密码错误 | 账号不存在 **或** 密码错（故意不区分，防账号探测） |
| 账号已被禁用 | 账号被管理员封了 |

### 4.3 退出登录

| 步骤 | 操作 |
|---|---|
| 1 | 点右上角**你的头像/昵称** |
| 2 | 下拉菜单里点「**退出登录**」 |

### 4.4 创建课程

1. 顶部「**课程**」→ 右上角「**新建课程**」
2. 填表单，只有**课程名称**是必填的
3. 点「**确定创建**」

> ⚠️ **如果提示"课程名称不能为空"**：说明名称为空，填上即可。

### 4.5 加入课程

1. 顶部「**课程**」
2. 找到目标课程卡片
3. 点卡片上的「**加入课程**」按钮（注意：点按钮不会跳转到详情页）

> ⚠️ **未登录时会提示"请先登录后再加入课程"**，并跳转到登录页。
> 登录后会自动跳回课程库。

### 4.6 上传资料（重点）

#### 入口有两个

| 入口 | 位置 |
|---|---|
| 入口 A | 课程详情页 → 右上角「**上传资料**」 |
| 入口 B | （未来会加到资料库页） |

#### 三个步骤

**第 1 步：选择文件**

- 方式一：点虚框 → 弹出系统文件选择框 → 选中文件 → 点"打开"
- 方式二：把文件从文件夹**直接拖进**虚框

**第 2 步：自动上传**

进度条会依次经过：

| 阶段 | 说明 | 进度区间 |
|---|---|---|
| 正在计算文件指纹 | 前端算整个文件的 MD5 | 0-20% |
| 检查服务端是否已有该文件 | 判断能否秒传 | 22% |
| 上传分片 | 5MB 一片依次上传 | 25-92% |
| 正在合并分片并校验完整性 | 服务端拼接并做 MD5 复验 | 94-100% |

> 💡 **如果显示"秒传成功"**：说明服务端已经有完全相同的文件，直接完成了。
> 💡 **如果中途失败**：重新上传同一个文件，**已传的分片不会重传**（断点续传）。

**第 3 步：填写信息**

| 字段 | 说明 |
|---|---|
| 资料标题 | 已自动填好（取文件名去掉扩展名），可以改 |
| 资料类型 | 讲义 / 教材 / 真题 / 笔记 / 作业 / 视频 / 其他 |
| **可见范围** | 见下方说明 ⬇️ |
| 资料描述 | 选填，建议写清楚内容 |

**可见范围怎么选**（重要）

| 选项 | 谁能看到 | 什么时候用 |
|---|---|---|
| **全平台公开** | 所有人，包括没登录的 | 通用的课件、真题 |
| **仅本课程** | 只有本课程成员和课程负责人 | 课程内部资料 |
| **仅自己可见** | 只有你自己 | 个人笔记、草稿 |

选完后点「**发布资料**」。

### 4.7 搜索资料

**方式一：关键词搜索**

1. 顶部「**资料库**」
2. 搜索框输入关键词（如"数据结构"）
3. 点「**搜索**」或按回车

**方式二：点热词**

热门搜索区域的标签，点一下就直接搜。

**方式三：按类型/课程筛选**

用下面的「全部类型」「全部课程」下拉框筛选。

> 💡 **搜索结果按"相关度"排序**，相关度显示在每条资料的右下角。
> 相关度越高说明匹配越好。

### 4.8 下载资料

1. 进入资料详情页（点资料卡片）
2. 点「**下载文件**」按钮
3. 浏览器开始下载，文件名保持原样（中文也正常）

> ⚠️ **必须先登录才能下载。**

### 4.9 修改资料信息

1. 进入资料详情页
2. 点「**编辑信息**」按钮（只有上传者/课程负责人/管理员能看到这个按钮）
3. 修改标题 / 类型 / 可见范围 / 描述
4. 点「**保存**」

### 4.10 删除资料

1. 进入资料详情页
2. 点「**删除资料**」按钮（红色）
3. 弹出确认框，点「**确定删除**」

> ⚠️ **删除是"逻辑删除"**：数据还在数据库里，只是标记为已删除，
> 列表里看不到。管理员可以恢复。

### 4.11 使用接口文档调试（进阶）

这是**不用写前端界面也能操作所有功能**的方式：

1. 浏览器打开 `http://localhost:8080/doc.html`
2. 左侧展开「**01-认证与用户**」→「**用户登录**」
3. 点右侧「**调试**」标签
4. 填 `{"username":"admin","password":"admin123"}`
5. 点「**发送**」
6. **复制响应里的 `token` 值**（很长的一串）
7. 点右上角「**文档管理**」→「**全局参数设置**」
8. 点「添加」，参数名填 `Authorization`，值填 `Bearer <刚才复制的token>`
   （注意 `Bearer` 后面**有一个空格**）
9. 点「确定」

**完成！** 现在所有需要登录的接口都能直接调试了。

## 五、常见问题排查

### 5.1 页面打不开

| 现象 | 检查 |
|---|---|
| 浏览器显示"无法访问" | 前端窗口是不是关了？重新 `npm run dev` |
| 页面能开但**状态卡片是红色** | 后端没起来，回去检查第 3 步 |
| 页面一片空白 | 按 F12 打开控制台看报错 |

### 5.2 登录不上

| 现象 | 解决 |
|---|---|
| 提示"账号或密码错误" | 用 `admin` / `admin123` 试试；或重新注册 |
| 登录后立刻又跳回登录页 | 后端可能重启了导致 Token 失效，重新登录 |

### 5.3 上传失败

| 提示 | 原因 | 解决 |
|---|---|---|
| 不支持的文件类型 | 扩展名不在白名单 | 只支持 PDF/Word/PPT/Excel/图片/压缩包 |
| 文件内容与扩展名不符 | 文件被改过后缀名 | 用正常文件 |
| 单个文件不能超过 500 MB | 文件太大 | 压缩后再传 |
| 上传失败，请重试 | 网络或后端问题 | 重新上传（已传的分片会保留） |

### 5.4 下载失败

| 现象 | 原因 |
|---|---|
| 提示"请先登录后再下载" | 未登录 |
| 下载下来是乱码文本 | 可能下载的是错误响应，检查后端日志 |

### 5.5 中文乱码

如果命令行窗口里中文显示成乱码 —— **这是正常的**，因为命令行的编码和文件编码不一致。
浏览器里显示是正常的。

### 5.6 想看看后端到底在干什么

打开后端窗口，会看到滚动的日志，例如：

```
登录成功 | userId=1 | username=admin | role=ADMIN
文件上传成功 | fileId=5 | name=数据结构.pdf | size=2621440
秒传命中 | hash=abc123... | fileId=5
发布资料 | resourceId=3 | courseId=1 | title=第二章 线性表
```

**每一条日志都对应你在界面上的一个动作**，对应着看很容易理解。

## 六、给不同角色的使用建议

### 如果你是学生使用者

常用流程：
```
登录 → 资料库搜索 → 找到资料 → 下载
      → 上传自己整理的笔记（设为"全平台公开"）
```

### 如果你是课程负责人

常用流程：
```
创建课程 → 上传课程资料（设为"仅本课程"）
        → 管理资料（编辑/删除）
        → 管理评论（删除不当评论）
```

### 如果你是管理员

除了上面的，还可以：
```
- 查看举报并处理（接口文档操作）
- 手动重算可信度评分（接口文档：POST /api/admin/recalc-score）
- 查看操作审计日志（接口文档：GET /api/admin/audit-logs）
```

### 如果你是开发者

打开 `http://localhost:8080/doc.html`，左侧能看到全部 **10 组、30+ 个接口**，
可以直接调试每一个。
